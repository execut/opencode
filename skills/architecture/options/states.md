# Состояния (states)
Обязательные опции: ddd-light

В DDD сущность (Entity) - это объект, который определяется своей идентичностью (ID), а не набором атрибутов, и у которого
есть жизненный цикл: он меняется со временем, сохраняя свою идентичность. Состояние сущности - это совокупность всех
её текущих атрибутов и инвариантов на данный момент.

Все свойства сущностей переезжают в специальный DTO `<Entity>State`, где `<Entity>` - название сущности.
- Теперь, чтобы получить значение свойства сущности, её геттер обращается к State и пробрасывает его свойство.
